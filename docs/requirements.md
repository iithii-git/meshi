# Meshi - レシピ・献立管理アプリ 要件定義書

## 1. プロジェクト概要

### 1.1 プロジェクト名
**Meshi（めし）** - AI搭載レシピ・献立管理アプリケーション

### 1.2 コンセプト
「1ヶ月先まで見える献立計画」と「AIによるレシピ提案」で、毎日の食事準備をストレスフリーに。

### 1.3 ターゲットユーザー
- 毎日の献立に悩む方
- 計画的に食事管理をしたい方
- 料理のレパートリーを増やしたい方
- 家族の食事を管理する方

---

## 2. 主要機能

### 2.1 ⭐ 献立カレンダー機能（コア機能）

#### 2.1.1 月間カレンダービュー
- **1ヶ月分の献立を一覧表示**
- 日付ごとに朝食・昼食・夕食を表示
- 視覚的にわかりやすいカラーコーディング
- 週間ビュー / 月間ビューの切り替え

#### 2.1.2 献立の登録・編集
- カレンダーから日付を選択して献立を設定
- ドラッグ&ドロップで献立の移動・コピー
- 繰り返し設定（毎週○曜日など）
- メモ・コメント機能

#### 2.1.3 献立の見やすさ向上
- 料理のカテゴリ別アイコン表示
- 栄養バランスインジケーター
- 調理時間の目安表示
- 材料の重複表示（まとめ買いに便利）

### 2.2 ⭐ AI献立提案機能（コア機能）

#### 2.2.1 AIレシピ生成
- **条件を指定してAIがレシピを提案**
  - 使いたい材料
  - 調理時間
  - カロリー目安
  - 料理ジャンル（和食・洋食・中華など）
  - 人数
  - アレルギー・NG食材

#### 2.2.2 AI献立プランニング
- 1週間分の献立を一括提案
- 栄養バランスを考慮した提案
- 食材の使い回しを考慮した効率的な提案
- 過去の履歴から好みを学習

#### 2.2.3 AIアシスタント機能
- 「冷蔵庫にある材料で何が作れる？」
- 「昨日は和食だったから今日は洋食を提案して」
- 「子供が喜ぶメニューを教えて」
- 自然言語での対話形式

### 2.3 レシピ管理機能

#### 2.3.1 レシピ登録
- 手動でレシピを登録
- 写真のアップロード
- 材料・分量・手順の入力
- カテゴリ・タグ付け
- 調理時間・難易度の設定

#### 2.3.2 レシピ検索
- キーワード検索
- 材料から検索
- カテゴリ・タグで絞り込み
- お気に入りフィルター

#### 2.3.3 レシピコレクション
- お気に入り登録
- マイレシピブック作成
- レシピの評価・メモ

### 2.4 買い物リスト機能

#### 2.4.1 自動生成
- 献立から必要な材料を自動抽出
- 期間を指定して買い物リスト作成
- 材料の重複をまとめて数量計算

#### 2.4.2 リスト管理
- カテゴリ別表示（野菜・肉・調味料など）
- チェックリスト形式
- 手動での追加・編集
- リストの共有機能

## 3. 技術要件

### 3.1 フロントエンド
- **フレームワーク**: Next.js (React)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **状態管理**: Zustand または Redux Toolkit
- **UIライブラリ**: shadcn/ui

### 3.2 バックエンド
- **フレームワーク**: Next.js API Routes または Node.js (Express)
- **言語**: TypeScript
- **データベース**: PostgreSQL
- **ORM**: Prisma

### 3.3 AI機能
- **LLM API**: OpenAI API (GPT-4) または Claude API
- AI応答のストリーミング対応
- プロンプトテンプレート管理

### 3.4 インフラ
- **ホスティング**: Vercel
- **データベース**: Supabase または PlanetScale
- **画像ストレージ**: Cloudflare R2 または AWS S3

## 5. データモデル

### 5.1 主要エンティティ

```
User（ユーザー）
├── id
├── email
├── name
├── preferences（食の好み・アレルギー）
└── createdAt

Recipe（レシピ）
├── id
├── title
├── description
├── imageUrl
├── servings（人数）
├── cookingTime（調理時間）
├── difficulty（難易度）
├── category（カテゴリ）
├── tags[]
├── ingredients[]（材料リスト）
├── steps[]（調理手順）
├── isAIGenerated
├── userId
└── createdAt

Ingredient（材料）
├── id
├── name
├── quantity
├── unit
└── recipeId

MealPlan（献立）
├── id
├── date
├── mealType（朝食/昼食/夕食）
├── recipeId
├── userId
├── note
└── createdAt

ShoppingList（買い物リスト）
├── id
├── name
├── startDate
├── endDate
├── items[]
├── userId
└── createdAt
```

## 6. 非機能要件

### 6.1 パフォーマンス
- ページ読み込み: 3秒以内
- AI応答開始: 2秒以内
- カレンダー操作: 遅延なし（60fps）

### 6.2 セキュリティ
- ユーザー認証（OAuth / メール認証）
- APIレート制限
- データの暗号化

### 6.3 ユーザビリティ
- レスポンシブデザイン（PC / タブレット / スマホ）
- オフライン対応（PWA）
- ダークモード対応

### 6.4 スケーラビリティ
- 1ユーザーあたり1000レシピ以上対応
- 同時接続1000ユーザー以上
