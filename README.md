# Meshi（めし）

AI搭載レシピ・献立管理アプリケーション

## コンセプト

「1ヶ月先まで見える献立計画」と「AIによるレシピ提案」、そして「スマート食材管理」で、毎日の食事準備をストレスフリーに。

## 主な機能

### 献立カレンダー
- 1ヶ月分の献立を一覧表示
- 朝食・昼食・夕食を日別に管理
- ドラッグ&ドロップで簡単編集
- 週間/月間ビューの切り替え

### AI献立提案
- 条件を指定してAIがレシピを提案
- 1週間分の献立を一括生成
- 栄養バランス・食材使い回しを考慮
- 自然言語での対話形式

### 食材管理
- 写真・レシートから食材を自動登録
- 冷蔵庫の中身を撮影して一括登録
- 在庫の残量・消費期限を管理
- なくなったら買い物リストに自動追加
- 期限が近い食材を優先したレシピ提案

### レシピ管理
- レシピの登録・検索・お気に入り
- 材料・手順・写真の管理
- カテゴリ・タグでの整理

### 買い物リスト
- 献立から自動生成
- 材料の重複をまとめて計算

## 技術スタック

- **フロントエンド**: Next.js, TypeScript, Tailwind CSS
- **バックエンド**: Next.js API Routes, Prisma
- **データベース**: PostgreSQL
- **AI**: OpenAI API / Claude API
- **インフラ**: Vercel, Supabase
